# Otel Rezervasyon Sistemi

## Proje Hakkında
Java programlama dili ile nesne tabanlı programlama yaklaşımı kullanılarak geliştirilmiş bir otel rezervasyon sistemidir.

## Özellikler
- Misafir kaydı oluşturma ve listeleme
- Oda seçimi
- Rezervasyon oluşturma
- Kayıtları listeleme ve arama
- Kayıt silme
- Dosyaya veri kaydetme ve dosyadan veri okuma

## Kullanılan Teknolojiler
- Java
- Nesne Tabanlı Programlama (OOP)
- Kalıtım (Inheritance)
- Metot ezme (Overriding)
- ArrayList
- Dosya İşlemleri (File I/O)
